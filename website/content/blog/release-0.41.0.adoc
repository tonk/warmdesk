A small release with two quality-of-life improvements for boards and the projects overview.

== Open cards first

Each board column's sort bar now has an *Open first* button. Click it and the open cards move above the closed ones. It works with the column's default order, so open cards keep the order you gave them, and with sorting by date, assignee, or priority. The setting is remembered per column in your browser. The button is only shown while closed cards are visible.

== Projects as a list

The dashboard has a new *Tiles* / *List* switch. The list view shows your projects in a table with their name, customer, board type, and number of open cards. Click a column header to sort by it, and click again to reverse the order. The customer filter works in both views, and your view and sort order are remembered in your browser.

See the link:../../docs/user-guide/[User Guide] for details.

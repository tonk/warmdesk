A patch release that fixes image uploads in the desktop app.

== Fixed

Uploading a customer logo, avatar, or other image in the desktop app failed with "file must be an image", even for a valid PNG or JPEG file. The image was damaged on its way to the server, so the server no longer recognised it. Uploads from the desktop app now arrive intact. The web interface was not affected.

== Upgrade

Download `v0.44.1` from the link:../../download[download page] or pull the latest release tag. No database migration or configuration change is needed. Only the desktop app needs updating to get the fix.

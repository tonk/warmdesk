Two small additions to the *My cards* view introduced in v0.43.0.

== A count on the My cards button

The *My cards* button on the dashboard now shows how many open cards are assigned to you, also while you are looking at the *Tiles* or *List* view, so you can see at a glance whether there is work waiting. The count follows the customer filter, is hidden when you have no open cards, and is read out by screen readers.

== my_cards Ansible lookup

The Ansible collection (now 0.6.6) has a new `ansilabnl.warmdesk.my_cards` lookup. It returns all open cards assigned to the user the credentials belong to, across all projects, with each card's reference (for example `EDA-42`), column, priority, due date, and project:

[source,yaml]
----
- name: Show my open cards
  ansible.builtin.debug:
    msg: "{{ item.card_ref }} [{{ item.column_name }}] {{ item.title }}"
  loop: "{{ query('ansilabnl.warmdesk.my_cards', url=warmdesk_url, api_key=warmdesk_key) }}"
----

Pass `project=` to limit the list to one project. The lookup needs a WarmDesk v0.43.0 or newer server.

WarmDesk `v0.12.9` contains a set of small refinements to the `--mode=timetracking` experience introduced in v0.12.7.

== Board report tab hidden in timetracking mode

The *Board* tab in the Time Tracking view gives access to the project-board time report.
In `--mode=timetracking`, project boards are not available, so the tab is now hidden entirely.

== Browser tab title

The browser tab (and desktop window title in the Tauri app) now reads *WarmDesk - Time Tracking* when the server runs in `--mode=timetracking`, making it easy to distinguish the window from a full WarmDesk instance running alongside it.
The `●` unread notification prefix still works correctly when combined with the new title.

== Upgrade

Download `v0.12.9` from the link:../../download[download page] or pull the latest release tag.
No database or configuration changes are required.

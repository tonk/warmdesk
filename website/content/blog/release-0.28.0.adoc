The weekly grid has had copy, cut, and paste for a long time. The calendar view didn't, so logging the same kind of entry on another day meant filling in the whole form again. `v0.28.0` adds copy and paste to the calendar's right-click menu.

== Copy a block, paste it anywhere

* *Right-click a block* and choose *Copy*. It sits next to the existing *Edit* and *Delete*.
* *Right-click an empty slot* and choose *Paste*. It's greyed out until you've copied something.

Pasting creates a new entry that starts at the slot you right-clicked. It gets the same customer, project, activity, distance, and location as the original, and the same duration. The original entry stays as it is.

If the duration would run past midnight, the pasted entry is cut off at the end of that day instead of spilling into the next one.

See the time tracking section of the link:../../docs/user-guide/[User Guide] for more on the calendar view.
